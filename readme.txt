مدیریت خودکار قیمت محصولات طلا، جواهر، سکه و شمش با دریافت قیمت بازار، فرمول‌های قابل تنظیم و بروزرسانی زمان‌بندی‌شده.

توسعه‌دهنده: Hassan Mojtahedi

== توضیحات ==
زرپالس قیمت پایه بازار را از API اختصاصی، خروجی JSON یا ورود دستی می‌گیرد و با فرمول‌های امن، قیمت محصولات ووکامرس را بروزرسانی می‌کند. قیمت محصول در سبد خرید مشتری قفل می‌شود تا نوسان‌های بعدی بازار سفارش قبلی را تغییر ندهد.

== نصب ==
1. فایل zip افزونه را از پیشخوان وردپرس > افزونه‌ها > افزودن > بارگذاری افزونه نصب و فعال کنید.
2. اطمینان بگیرید ووکامرس فعال است.
3. از منوی زرپالس > تنظیمات عمومی، ورود دستی و زمان‌بندی را تعیین کنید.
4. در منوی منابع قیمت، API یا JSON خود را اضافه و تست کنید.
5. در صفحه ویرایش هر محصول، تب قیمت‌گذاری طلا را تکمیل کنید.

== فرمول‌ها ==
فقط عدد، متغیرهای ارائه‌شده، پرانتز و عملگرهای + - * / پشتیبانی می‌شوند. اجرای کد در فرمول ممکن نیست.

نمونه فرمول شمش:
((weight * base_18k * karat_factor) + wage + extra + packing + insurance + manufacturing + profit_fixed) * (1 + profit_percent / 100) * (1 + tax_percent / 100)
