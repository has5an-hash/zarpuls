# سناریوهای کنترل کیفیت زرپالس ۱.۱.۰

## محیط مرجع
- وردپرس ۶.۲ یا بالاتر با یک پوسته پیش‌فرض
- ووکامرس ۷.۵ یا بالاتر
- PHP ۷.۴ یا بالاتر
- بدون افزونه جانبی (به‌جز ووکامرس)

## چک‌لیست عملکرد

1. نصب zip افزونه از پیشخوان بدون ایجاد پوشه تو در تو.
2. فعال‌سازی با ووکامرس فعال؛ بررسی ظاهرشدن منوی زرپالس.
3. غیرفعال‌کردن ووکامرس؛ بررسی نمایش پیام وابستگی بدون خطای PHP.
4. درج قیمت دستی ۱۸ عیار، ساخت یک شمش ۱ گرمی با فرمول آماده و بررسی قیمت نهایی.
5. افزودن منبع JSON آزمایشی معتبر و آزمون دکمه «ذخیره و تست اتصال».
6. افزودن دو منبع با اولویت متفاوت و قطع منبع اول؛ بررسی استفاده از منبع دوم.
7. واردکردن API Key و Header؛ بررسی اینکه در ویرایش مجدد فقط حالت ماسک‌شده دیده می‌شود.
8. ساخت فرمول معتبر، محاسبه پیش‌نمایش و ذخیره آن روی محصول.
9. تلاش برای درج عبارت نامعتبر مانند `system()`، `^` یا تقسیم بر صفر؛ بررسی ردشدن امن فرمول.
10. اجرای «دریافت قیمت و بروزرسانی محصولات»؛ بررسی regular price و price محصول.
11. افزودن محصول به سبد، تغییر نرخ بازار و بروزرسانی محصول؛ بررسی ثابت ماندن قیمت همان سبد.
12. تکمیل سفارش؛ بررسی متای «قیمت قفل‌شده زرپالس» روی آیتم سفارش.
13. تنظیم آستانه هشدار کم، تغییر قیمت ۱۸ عیار و بررسی ثبت رخداد هشدار.
14. بررسی بخش «تنظیم Cron واقعی سرور»: نمایش وضعیت wp-config.php و کارکرد دکمه «تنظیم خودکار» (در صورت قابل‌نوشتن بودن فایل).
15. بررسی موبایل و راست‌چین بودن پنل مدیریت.

## کنترل نهایی پیش از انتشار
- اسکن فایل نهایی با VirusTotal.
- تست روی محیط استاندارد وردپرس و ووکامرس.
- ثبت نسخه، تاریخ بروزرسانی و changelog.
- حذف هر نوع اطلاعات تماس، لینک شخصی و کلید API از zip، دمو و راهنما.
