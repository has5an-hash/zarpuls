# راهنمای کامل افزونه زرپالس

**توسعه‌دهنده: حسن مجتهدی | Hassan Mojtahedi**
## قیمت‌گذاری هوشمند طلا و جواهر برای ووکامرس — نسخه ۱.۱.۰

زرپالس برای فروشگاه‌هایی ساخته شده که قیمت شمش، طلای آب‌شده، زیورآلات، جواهر، سکه یا کالای سفارشی را بر اساس نرخ روز محاسبه می‌کنند. این افزونه قیمت پایه را دریافت می‌کند، فرمول انتخابی شما را روی اطلاعات محصول اجرا می‌کند و قیمت ووکامرس را به‌صورت زمان‌بندی‌شده بروزرسانی می‌نماید.

> **پیش‌نیازها:** وردپرس ۶.۲ یا جدیدتر، ووکامرس ۷.۵ یا جدیدتر، PHP ۷.۴ یا جدیدتر و فعال بودن WP-Cron. برای بروزرسانی منظم در فروشگاه کم‌ترافیک، Cron واقعی سرور پیشنهاد می‌شود.

---

## ۱. نصب و فعال‌سازی

1. فایل `zarpulse-gold-pricing.zip` را از مسیر **پیشخوان > افزونه‌ها > افزودن > بارگذاری افزونه** انتخاب و نصب کنید.
2. افزونه را فعال کنید. در صورت غیرفعال بودن ووکامرس، پیام پیش‌نیاز نمایش داده می‌شود.
3. منوی **زرپالس** در پیشخوان وردپرس ظاهر می‌شود.
4. از **زرپالس > تنظیمات عمومی**، ابتدا قیمت‌های دستی را وارد کنید تا همیشه یک مسیر امن جایگزین برای دریافت قیمت وجود داشته باشد.

---

## ۲. راه‌اندازی سریع

### گام اول: ورود قیمت پایه

در بخش تنظیمات عمومی، این پنج قیمت قابل ثبت هستند:

- هر گرم طلای ۱۸ عیار
- هر گرم طلای ۲۴ عیار
- سکه
- اونس جهانی
- نرخ ارز

ورود دستی، «آخرین منبع» است؛ یعنی تا وقتی منبع آنلاین قیمت معتبری برگرداند، همان منبع استفاده می‌شود. عدد صفر به معنی استفاده‌نشدن از آن قیمت است.

### گام دوم: اتصال API یا JSON

در **زرپالس > منابع قیمت** یک منبع تازه ایجاد کنید. برای هر منبع این موارد را وارد کنید:

- نام منبع و اولویت (عدد کوچک‌تر، اولویت بالاتر)
- URL سرویس
- متد `GET`، `POST` یا `PUT`
- API Key اختیاری (به شکل رمزگذاری‌شده ذخیره می‌شود)
- Header و پارامترها به‌صورت JSON
- نقشه مسیر قیمت‌ها به‌صورت JSON

نمونه خروجی API:

```json
{
  "data": {
    "gold18": 25000000,
    "gold24": 33333333,
    "coin": 320000000
  }
}
```

نمونه نقشه برای این خروجی:

```json
{
  "18k": "data.gold18",
  "24k": "data.gold24",
  "coin": "data.coin"
}
```

روی «ذخیره و تست اتصال» کلیک کنید. اگر منبع اول پاسخ ندهد، زرپالس برای هر قیمت به منبع بعدی و در نهایت ورود دستی می‌رود.

### گام سوم: فرمول قیمت‌گذاری

سه فرمول آماده برای شمش/آب‌شده، جواهر و سکه وجود دارد. از بخش **فرمول‌ها** می‌توانید آن‌ها را ویرایش یا فرمول تازه بسازید.

مثال فرمول جواهر:

```text
((weight * base_18k * karat_factor) + wage + stone + extra + packing + insurance + manufacturing + profit_fixed) * (1 + profit_percent / 100) * (1 + tax_percent / 100)
```

فرمول فقط از عدد، متغیرهای افزونه، پرانتز و عملگرهای `+`، `-`، `*` و `/` تشکیل می‌شود. کد PHP یا JavaScript در فرمول اجرا نمی‌شود.

### گام چهارم: تنظیم محصول

در صفحه ویرایش محصول ووکامرس، تب **قیمت‌گذاری طلا** را باز کنید:

1. «فعال‌سازی قیمت هوشمند» را تیک بزنید.
2. نوع محصول، وزن و عیار را ثبت کنید.
3. فرمول را انتخاب کنید.
4. اجرت، سنگ، سود، مالیات و سایر هزینه‌ها را وارد کنید.
5. روی «محاسبه قیمت» بزنید و سپس محصول را ذخیره کنید.

با ذخیره محصول، قیمت عادی ووکامرس با خروجی فرمول جایگزین می‌شود.

---

## ۳. فرهنگ متغیرهای فرمول

| متغیر | کاربرد |
|---|---|
| `weight` | وزن محصول بر حسب گرم |
| `base_18k` و `base_24k` | قیمت پایه طلای ۱۸ و ۲۴ عیار |
| `coin` | قیمت پایه سکه |
| `ounce` و `exchange` | اونس جهانی و نرخ ارز |
| `karat_factor` | عیار محصول تقسیم بر ۱۸ |
| `wage` | اجرت ثابت |
| `stone`، `extra`، `packing` | سنگ، هزینه اضافه و بسته‌بندی |
| `shipping`، `insurance`، `manufacturing` | ارسال، بیمه و هزینه ساخت |
| `profit_percent` و `profit_fixed` | سود درصدی و ثابت |
| `tax_percent` | مالیات درصدی |

## ۴. زمان‌بندی، قیمت قفل‌شده و هشدار

- بروزرسانی قیمت به‌صورت خودکار و لحظه‌ای (هر دقیقه) همیشه فعال است و نیازی به تنظیم دستی ندارد.
- پس از دریافت قیمت جدید، محصولاتی که قیمت‌گذاری هوشمندشان فعال است بروزرسانی می‌شوند.
- با افزودن کالا به سبد، قیمت واحد همان لحظه روی آیتم سبد ذخیره می‌شود. تغییرات بعدی بازار، قیمت سفارش در حال خرید یا سفارش ثبت‌شده را تغییر نمی‌دهد.
- در صورت تغییر قیمت بیش از آستانه تعریف‌شده، رویداد هشدار ثبت و در صورت تکمیل ایمیل، پیام اطلاع‌رسانی ارسال می‌شود.

### Cron واقعی سرور

WP-Cron فقط وقتی بازدیدکننده‌ای وارد سایت شود اجرا می‌شود؛ بنابراین در ساعات کم‌ترافیک قیمت‌ها عقب می‌افتند. برای بروزرسانی واقعاً لحظه‌ای، در **زرپالس > تنظیمات عمومی > تنظیم Cron واقعی سرور** این دو کار را انجام دهید:

1. آدرس آمادهٔ وظیفه زرپالس (محافظت‌شده با توکن اختصاصی) را کپی و در پنل هاست یک Cron Job هر ۱ دقیقه تنظیم کنید.
2. روی دکمهٔ «تنظیم خودکار wp-config.php» کلیک کنید تا خط `define( 'DISABLE_WP_CRON', true );` خودکار اضافه شود (اگر فایل قابل نوشتن نباشد، راهنمای دستی نمایش داده می‌شود).

## ۵. پروفایل دسته و گزارش‌ها

در تنظیمات عمومی می‌توان برای هر دسته محصول، فرمول و سود پیش‌فرض تعیین کرد. اگر مقدار فرمول یا سود در محصول مشخص نشده باشد، مقدار پیش‌فرض دسته اعمال می‌شود.

در **گزارش‌ها** می‌توانید آخرین نرخ‌های ثبت‌شده، زمان و منبع هر نرخ و رویدادهای ۳۰ روز اخیر را ببینید. خطاهای اتصال منبع و خطاهای محاسبه نیز در همین بخش ثبت می‌شوند.

---

## ۶. نکات عیب‌یابی

| مسئله | راه‌حل |
|---|---|
| قیمت صفر است | قیمت دستی یا منبع آنلاین و مسیر JSON را بررسی کنید. |
| منبع پاسخ نمی‌دهد | با «ذخیره و تست اتصال» کد و متن خطا را بررسی کنید؛ منبع جایگزین یا ورود دستی را فعال نگه دارید. |
| محصول بروزرسانی نمی‌شود | فعال بودن گزینه قیمت هوشمند و مقدار فرمول محصول را بررسی کنید؛ سپس Cron وردپرس را بررسی کنید. |
| قیمت سبد با قیمت جدید فرق دارد | این رفتار طبیعی «قفل قیمت» است؛ محصول در زمان ورود به سبد قیمت خودش را ذخیره کرده است. |
| فرمول ذخیره نمی‌شود | فقط متغیرهای جدول و عملگرهای مجاز را به‌کار ببرید؛ از کاما، حروف فارسی در نام متغیر و عملگرهای دیگر استفاده نکنید. |

## ۷. بروزرسانی ایمن

1. از پایگاه داده و فایل‌های سایت نسخه پشتیبان بگیرید.
2. فایل zip نسخه جدید را از بخش افزونه‌ها بارگذاری و جایگزین کنید.
3. یک‌بار از داشبورد زرپالس «دریافت قیمت و بروزرسانی محصولات» را اجرا کنید.
4. یک محصول آزمایشی، سبد خرید و ثبت سفارش را بررسی کنید.

حذف عادی افزونه، داده‌های قیمت و تنظیمات را حذف نمی‌کند تا نصب مجدد ایمن باشد. پیش از حذف کامل داده‌ها از دیتابیس حتماً نسخه پشتیبان تهیه کنید.

---

## ۸. رزرو قیمت و تایمر تسویه‌حساب

زرپالس برای جلوگیری از اختلاف نرخ بین ورود کالا به سبد و پرداخت، برای **هر آیتم سبد به‌صورت مستقل** یک مهلت رزرو قیمت ایجاد می‌کند.

- این قابلیت به‌طور پیش‌فرض فعال و مدت آن **۵ دقیقه** است.
- هر محصول زمان خودش را دارد؛ برای نمونه اگر یک شمش در ساعت ۱۰:۰۰ و یک انگشتر در ساعت ۱۰:۰۳ به سبد اضافه شوند، تایمر هر یک مستقل نمایش داده می‌شود.
- با پایان زمان هر آیتم، همان محصول از سبد حذف می‌شود و مشتری باید آن را دوباره با نرخ جدید اضافه کند.
- پس از ثبت سفارش، مهلت رزرو به‌عنوان متای آیتم سفارش ثبت می‌شود.

### تنظیمات نمایش

از مسیر **زرپالس > تنظیمات عمومی > رزرو قیمت و تایمر پرداخت** می‌توانید:

1. قفل زمان‌دار قیمت را روشن یا خاموش کنید.
2. مدت رزرو را از ۱ تا ۱۲۰ دقیقه تعیین کنید.
3. نمایش خودکار را انتخاب کنید تا تایمر در مینی‌کارت، سبد و تسویه‌حساب نشان داده شود.
4. حالت «نمایش سفارشی با شورت‌کد» را انتخاب کنید و شورت‌کد زیر را در برگه/قالب مورد نظر بگذارید:

```text
[zarpulse_price_lock_timer]
```

پس از افزودن محصول، یک پنجره اطلاع‌رسانی حرفه‌ای نیز مهلت پرداخت را اعلام می‌کند.

## ۹. الگوهای پیش‌فرض قیمت‌گذاری بازار ایران

زرپالس الگوهای زیر را به‌صورت پیش‌فرض قرار می‌دهد؛ همه آن‌ها قابل ویرایش هستند و مدیر فروشگاه مسئول تطبیق نهایی با فاکتور، منبع نرخ، مقررات صنفی و مالیاتی خود است.

### مصنوعات طلا و جواهر

```text
ارزش خام = وزن × نرخ هر گرم × ضریب عیار
اجرت = اجرت ثابت + (وزن × اجرت هر گرم) + (ارزش خام × اجرت درصدی)
سود = (ارزش خام + اجرت + خدمات) × درصد سود
مالیات = (اجرت + خدمات + سود) × درصد مالیات
قیمت نهایی = ارزش خام + اجرت + خدمات + سود + مالیات
```

در الگوی پیش‌فرض، مالیات روی ارزش ذاتی طلای خام اعمال نمی‌شود؛ فقط اجرت، سود و خدمات مشمول مبنای مالیات هستند. برای مصنوعات، سود پیش‌فرض ۷٪ و مالیات پیش‌فرض ۱۰٪ در نظر گرفته شده و هر دو قابل تغییرند.

### شمش و طلای آب‌شده

ارزش طلا بر پایه وزن و عیار محاسبه می‌شود؛ سپس کارمزد، بسته‌بندی، بیمه و سود کم‌تری اعمال می‌گردد. مالیات در الگوی دمو صفر است و مدیر فروشگاه باید آن را مطابق وضعیت حقوقی کالای خود تنظیم کند.

### سکه و پارسیان

قیمت پایه سکه به‌همراه کارمزد، بیمه، ارسال و سود محاسبه می‌شود. مالیات پیش‌فرض این الگو صفر است؛ چون وضعیت مالیاتی و حباب/کارمزد سکه باید بر اساس مدل فروشگاه تنظیم شود.
